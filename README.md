# הצהרת הפקדות

אפליקציה למשק ת"ש: קוראת עו"ש (PDF מקורי מהבנק או אקסל), בוחרת לפי הכללים את הפעולות שדורשות הצהרה,
שולחת אותן נעולות לחייל למילוי הסברים, ומפיקה את הטופס הרשמי (נספח ו' לסיוע כלכלי, נספח ג' לתשמ"ש).

בלי AI ובלי שרת: כל הנתונים נשמרים רק בדפדפן של המשק. ההצהרה עוברת לחייל וחזרה בתוך קישור בוואטסאפ.

## איך זה מגן מטעויות ומרמאות

- **קריאת העו"ש**: כל שורה נבדקת מול עמודת היתרה (יתרה קודמת ± סכום = יתרה חדשה). שורה חסרה, סכום שגוי או
  קריאה לא נכונה גורמים לאזהרה אדומה, והמשק חייב לאשר ידנית כדי להמשיך.
- **מקור הקובץ**: האפליקציה מכירה את הפורמטים של הבנקים (שורת הכותרות והתוכנה שהבנק מפיק בה את הקובץ), לפי קבצים אמיתיים. טבלה של בנק מוכר שנוצרה בתוכנה אחרת מקבלת אזהרה. הפורמטים מוטמעים בקוד (`src/lib/fingerprint.ts`) ושום דבר לא נלמד או נשמר במכשיר.
- **דף הסבר**: `about.html` מסביר את הכלי למשקים, לקצינות ת"ש ולמפקדים, ומפנה לאפליקציה.
- **החייל**: יכול לכתוב רק הסבר, הערת "לא מסכים" ופרטים אישיים. תאריכים וסכומים נלקחים תמיד מהעותק שנשמר
  אצל המשק, ותשובה שהחותמת שלה לא תואמת, שחסרות בה שורות או ששייכת לסבב ישן נדחית.

## הכללים

- שום שורה לא נבחרת אוטומטית: המשק בוחר בעצמו. שורות שעומדות בכללי הנוהל מקבלות רמז.
- סיוע כלכלי: הפקדות ומשיכות נבדקות בנפרד. רמז לכל פעולה מעל 200 ₪ בחודש שהסכום בו עולה על 600 ₪.
- תשמ"ש: רמז להכנסה מ-250 ₪ ולהוצאות רכב. המשק מסווג כל הכנסה שבחר כקבועה או חד פעמית.


הכללים נמצאים ב-`src/lib/rules.ts`, קריאת הטבלה ב-`src/lib/grid.ts`, וקריאת PDF ב-`src/lib/pdfgrid.ts`.

## הרצה

```
npm install
npm run dev      # פיתוח
npm test         # בדיקות
npm run build    # בנייה לתיקיית dist, אתר סטטי שאפשר לאחסן בכל מקום
```
